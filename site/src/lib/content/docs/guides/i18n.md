# Internationalisation

Everything a reader sees or hears is keyed by locale; nothing language-specific lives in code or scene geometry.

| Layer | Per-locale file | Fallback |
|---|---|---|
| Interface | `content/ui/<locale>.json` (`t(dict, key, vars)`) | default locale, then the key |
| Story text | `content/stories/<locale>/<slug>.json` | `fr-CA → fr → default`, with a "not yet translated" note |
| Scene text | `content/films/<slug>/strings/<locale>.json` (`{{key}}`) | merged along the same chain |
| Voice + captions | `content/films/<slug>/voice/<locale>.json` | none: a locale without voice ships captions-only or no video |
| Timing | `timing.<locale>.json` | `timing.json`, then design times |
| Video | `production/<slug>/<locale>/out/…` | n/a |

## Routing and SEO

`/<locale>/…` for every page (the default locale may also live at `/`). Negotiate the first visit from
`Accept-Language` (`negotiate()`), then keep the reader's choice. Prerender every story per locale; add `hreflang`
alternates (and `x-default`), localized `<title>`, description and `og:image` (the locale's cover). Dates and
numbers through `Intl` (`formatDate`, counters are locale-formatted automatically).

## Translation workflow

1. Freeze the default-locale story (owner-approved) before translating.
2. Claude drafts each locale (the `localizer` agent): story body, scene strings, voice script, UI strings; keeps keys
   identical; adapts examples and idioms rather than translating them literally; keeps the punchline short.
3. A native reviewer approves in the review sheet (one row per locale). Legal/regulated wording is reviewed by a
   person, always.
4. `emaki validate` must pass (every `{{key}}` present in every locale), then a contact sheet per locale.
5. Voice, fit, render, build per locale.

## Layout across languages

- Size for the longest language; let lines wrap; check each locale's sheet. Use `locales.<code>.css` in a scene for
  exceptions rather than separate scene files.
- RTL (`ar`, `he`, `fa`, `ur`): `dir="rtl"` on the page and stage; place heads on the right with a locale CSS block
  if the composition reads left-to-right (arrows, timelines), otherwise leave the art as is.
- Fonts: confirm glyph coverage per locale (diacritics, CJK, Arabic); load the font subsets for each locale only.
